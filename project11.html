Project Overview

This project focused on building a trader-facing visualization workflow from raw quote ingestion to front-end charting. Across three repositories, I worked through the full path of consuming live quote data, structuring it for analysis, and rendering a dashboard that surfaces pricing trends and alert conditions for a pair of stocks.

Project Highlights

3 Linked Tasks
500 Quote Requests
2 Tracked Stocks
5% Alert Threshold
  • Parsed streaming quote data and extracted bid, ask, and price values with Python.
  • Built a React and TypeScript dashboard using the Perspective visualization library.
  • Calculated stock price ratios and highlighted alert conditions when the spread moved out of range.
  • Organized the work as progressive deliverables across data processing, front-end charting, and alert logic.

Implementation Across Tasks

Task 1: Market Data Processing

  • Consumed quote responses from a local pricing server.
  • Extracted stock symbol, bid price, ask price, and computed display price values.
  • Added unit-test coverage around quote parsing behavior and pricing edge cases.

Task 2: Visualization Layer

  • Integrated Perspective into a React application for interactive chart rendering.
  • Configured timestamp-based visualization of top bid and ask values.
  • Streamed server responses into the dashboard to keep the graph updated with incoming data.

Task 3: Ratio Monitoring & Alerts

  • Computed normalized price ratios between two tracked stocks.
  • Introduced upper and lower bounds to detect outlier trading conditions.
  • Extended the chart schema to visualize ratio movement and trigger-alert signals together.

Dashboard Features
