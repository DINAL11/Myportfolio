MetaCoreLife Social Platform

A social platform for personal growth built around health, wealth, and relationships, combining community features with challenge tracking, badges, discovery, and monetization-ready product flows.

Live Site GitHub

Project Overview

MetaCoreLife is designed as a purpose-driven alternative to traditional social media. Instead of optimizing around vanity metrics and endless scrolling, the platform is centered on meaningful progress through challenges, streaks, community updates, and products tied to self-improvement.

What I Built

  • Designed the product around three core themes: health, wealth, and relationships.
  • Built feed, profile, challenge, search, and guest exploration flows into one cohesive experience.
  • Integrated Stripe-backed commerce to support future premium features, product sales, and monetization experiments.
  • Structured the app as a startup-ready foundation rather than a one-off demo build.

Core Features

Community Feed

Discovery-oriented posts, challenge completions, and progress updates.

Challenges

Curated routines with progress tracking, streaks, and completion flows.

Badges & Profile

Visible progress markers, stats, active challenges, and user identity.

Marketplace

Commerce hooks for wellness and personal-growth oriented products.

Architecture & Stack

React Frontend
Supabase Backend & Auth
Stripe Payments
Vite Build Tooling
  • Frontend: React 19, Vite, Tailwind CSS, Lucide React
  • Backend Services: Supabase PostgreSQL, Auth, and Realtime capabilities
  • State Management: React Context for auth, cart, and challenge flows
  • Payments: Stripe integration for premium and marketplace directions
