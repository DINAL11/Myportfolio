Woyage — Modern Storefront

A fast e-commerce storefront with instant search, category filters, sorting, star ratings, discount badges, and a slide-out cart with quantity controls.

GitHub

Project Overview

Woyage is a production-quality storefront demo powered by the DummyJSON products API. It showcases modern React patterns — client-side filtering, responsive grids, loading skeletons, and a polished cart drawer experience.

Highlights

Instant Search

Filter products by title and description in real time.

Cart Drawer

Slide-out cart with quantity steppers and live subtotal.

Responsive

2-to-4 column grid that adapts across breakpoints.
