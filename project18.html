Focus Dashboard

A calm, all-in-one productivity workspace — daily planner, Pomodoro timer, habit tracker, goals, analytics, and reflection journal. Privacy-first with local storage.

GitHub

Project Overview

Focus Dashboard is a second-brain style productivity app built with Next.js 15 and React 19. It combines planning, focus sessions, habits, and progress tracking in one polished interface with dark/light themes and zero backend dependencies.

Highlights

Real Pomodoro

Focus/short-break/long-break cycles with progress ring and session counting.

Live Analytics

Recharts-powered stats for tasks, completion rate, and goal progress.

Private by Design

All state persisted in localStorage — no account or server required.
